# 🛡️ Fiche Métier — Ingénieur en Cybersécurité

Site web de présentation d'un métier du numérique, réalisé dans le cadre de
l'**atelier de professionnalisation du BTS SIO**.

🔗 **Site en ligne :** https://shiro14v.github.io/

---

## 📌 Présentation du projet

Une page interactive pour découvrir le métier d'**ingénieur en cybersécurité** :

- rôle et missions quotidiennes ;
- les 4 axes d'analyse : diplôme, salaire, lieu et conditions d'exercice ;
- le secteur en chiffres, les spécialisations, les formations et la carrière ;
- des liens vers les sources officielles (ONISEP, ANSSI).

## 🧰 Technologies utilisées

| Technologie | Rôle |
|---|---|
| HTML5 | Structure et contenu de la page |
| CSS3 | Présentation, charte graphique, mode sombre |
| Bootstrap 5 | Responsive design et composants (navbar, cartes, tableaux…) |
| JavaScript | Interactivité : mode sombre et animation "terminal" |

## ✨ Fonctionnalités

- ✅ Page **multi-support** : la mise en page se réorganise selon la taille de l'écran
- 🌙 **Mode sombre / clair** avec mémorisation du choix (localStorage)
- ⌨️ **Animation** "machine à écrire" effet terminal
- 📖 Définitions **dépliables** (ESN, cadre légal de l'astreinte)
- 📊 Chiffres clés et tableaux de salaires
- ♿ Accessibilité : lien d'évitement, attributs ARIA, respect de `prefers-reduced-motion`
